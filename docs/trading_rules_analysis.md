### 策略3（1小时趋势）

#### 优劣势判断规则

**数据采集**:
- 每5秒记录UP价格
- 持续采集10分钟

**判断公式**:
```
优势方计算 = (低于50的次数) - (高于50的次数)
- 如果 > 0：DOWN为优势方
- 如果 < 0：UP为优势方
```

**额外条件**（劣势方筛选）:
1. 前10分钟内，劣势方没有低于40
2. 劣势方的5秒记录中，>50和<50的次数都有
3. >50次数 : <50次数 比例 ≥ 1:2

#### 买入点

| 条件 | 详情 |
|------|------|
| **选择方向** | 劣势方 |
| **价格区间** | 35-45 |
| **买入限制** | 每小时最多1次 |

#### 卖出点

| 类型 | 条件 | 详情 |
|------|------|------|
| **止盈** | 价格上涨10点 | 35买→45卖，45买→55卖 |
| **止损1** | BTC趋势加强 | BTC价格向优势方变化超过买入时变化的50% |
| **止损2** | 时间截止 | 已过40分钟，未反弹且BTC价格继续向优势方增加 |

| **止损** | 无 | 根据任务2要求，买入后持有到最后 |

| 类型 | 触发条件 | 操作 |
|------|----------|------|
| **止盈** | 价格 ≥ 买入价 + 10 | 立即卖出 |
| **止损** | BTC变化 > 买入时的50% (向优势方) | 立即卖出 |

## 四、ROI和风险评估

### 策略1（A段回弹）

#### 收益分析
| 场景 | 买入价 | 结算价 | 收益率 |
|------|--------|--------|--------|
| 最佳 | 30 → 回弹到100 | 100 | **+233%** |
| 一般 | 30 → 结算归零 | 0 | **-100%** |
| 预期 | 30 → 50概率回弹 | ~50 | **+67%** |

#### 风险因素
- ⚠️ **高风险**: 剩余10-15分钟，回弹时间较短
- ⚠️ **假突破风险**: 1分钟内急跌可能是真实趋势
- ✅ **优势**: BTC价格下跌<50点，说明整体趋势不明显

#### 预期ROI
- 假设胜率50%，买入价30
  - 赢：(100-30)/30 = +233%
  - 输：-100%
  - **期望值**: 0.5 × 2.33 + 0.5 × (-1) = **+66.5%**
